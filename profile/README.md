## About Knowledge Base International Schools

**Knowledge Base International Schools (KBI)** is a private school in **Apapa, Moniya, Ibadan, Nigeria**, offering small class sizes, individual education plans and a wide, varied curriculum — including **STEM, coding and robotics education** — in a loving, high-standard learning environment.

This organisation hosts the school's public GitHub Pages site and the digital resources built to support its STEM programme, developed and maintained in partnership with [Babatunde Awoyemi](https://github.com/babatundeawo) / [Techbase Consultant Services](https://github.com/techbaseng).

```yaml
school: Knowledge Base International Schools
location: Apapa, Moniya, Ibadan, Oyo State, Nigeria
programme: STEM, Coding & Robotics Education
stem_lead: Babatunde Awoyemi (Lead Consultant, since January 2022)
website: https://kbischools.com.ng
```

## 🤝 About Our STEM Partnership

KBI's STEM, coding and robotics pathway is led by [Babatunde Awoyemi](https://github.com/babatundeawo), who also leads [Techbase Consultant Services](https://github.com/techbaseng) — the free, open STEM curriculum (HTML, CSS, JavaScript, Python and Scratch) that KBI students learn from. Explore the free courses at [techbaseng.github.io](https://techbaseng.github.io/).
